# Conventional Context

**Keep people aware and in charge of what AI agents build.**

Conventional Context is a schema for [OpenSpec](https://github.com/Fission-AI/OpenSpec), plus a `docs/context/` folder where people write down a project's requirements, constraints, and decisions. Agents check every change against them, and a GitOps workflow (pull requests and a protected `main` branch) makes sure a person approves every change.

- [conventionalcontext/conventionalcontext](https://github.com/conventionalcontext/conventionalcontext): the schema and templates
- [conventionalcontext.org](https://conventionalcontext.org): the website

Questions and ideas: open an issue in the main repository. See [SUPPORT.md](https://github.com/conventionalcontext/.github/blob/main/SUPPORT.md).
