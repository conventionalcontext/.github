## How decisions are made

- **Every change is a pull request.** The `main` branch of each public repository is protected: a pull request needs approval from someone other than the person who pushed last, and nobody can bypass that, including Owners. With two maintainers, every change needs the other maintainer's approval.
- **Lasting decisions are written down** as decision records in the main repository's [`docs/context/decisions/`](https://github.com/conventionalcontext/conventionalcontext/tree/main/docs/context/decisions). A decision starts as `proposed` and becomes `accepted` when both maintainers approve it in a pull request.
- **Disagreement:** discuss in the pull request or issue. If the maintainers still disagree, the change does not go ahead; the current state stays.

## Adding or removing a maintainer

- A new maintainer is added when all current maintainers agree, recorded in a pull request that updates this file.
- A maintainer can step down at any time by updating this file. Their access is removed after the pull request merges.
- Project accounts (domain, mailbox, GitHub organizations) are owned by the project, not by one person, and are handed over following the project's private runbook.
