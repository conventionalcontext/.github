# Custody of project assets

The public record of what the Conventional Context project owns, so anyone can check that the project, not one person, controls it. Credentials are never stored here or in any repository.

| Asset | Details | Held by |
|---|---|---|
| Domain `conventionalcontext.org` | Registered 2026-10-05, expires 2027-10-05, auto-renew on, registrar lock on, WHOIS privacy on | The project's registrar account, signed in through the project mailbox |
| Domain `conventional-context.org` | Not registered. Decided at the first traction checkpoint (2027-07-05) | |
| Email `hello@`, `security@`, `conduct@` `conventionalcontext.org` | Forward to the project mailbox | Both maintainers |
| GitHub organization `conventionalcontext` | The project. Domain verified | Both maintainers, as Owners |
| GitHub organization `conventional-context` | Held so nobody else can take the name; points to `conventionalcontext` | Both maintainers, as Owners |

## How custody is kept

- Every account belongs to the project mailbox, not to a maintainer's personal account. Both maintainers can sign in.
- GitHub settings are managed as code and reviewed like any other change.
- Accounts, domains, and access are reviewed once a year.
